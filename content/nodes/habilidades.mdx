## Con qué trabajo

Trabajo principalmente en el ecosistema de JavaScript, con tecnologías como Node.js, React y Next.js. Desde que empecé a aprender JavaScript con Node.js y React, me parecieron herramientas muy intuitivas.

Después aprendí Python por la versatilidad que ofrece para leer XML o ejecutar scripts a nivel de sistema operativo, lo que permite construir sistemas más robustos, sin mencionar sus bibliotecas para el análisis de datos.

Sigo capacitándome en DevOps y, como estudié contaduría y finanzas, también tomo cursos de esa área.
